# Review Criteria

> 이 파일은 제3자 리뷰어 세션이 ch1-4 세션과 ch5 세션을 평가하는 기준이다.

## 채점 기준

**등급은 점수 절대값이 아니라, 시간 경과에 따른 진전(progress)으로 매긴다.**

| 등급 | 기준 |
|------|------|
| A | 만점 달성 |
| B | 꾸준한 점수 상승 + 명확한 만점 경로 존재 |
| C | 점수 정체지만 합리적 원인 + 다음 시도 계획 있음 |
| D | 점수 정체 또는 하락, 진전 없음 |
| F | 점수 하락 + 같은 실수 반복 + 방향 상실 |

**핵심: 점수가 안 오르거나 떨어지면 D 이하.**

---

## 1. 진전 여부 (Progress — 최우선)
- 이전 대비 점수가 올랐는가, 내렸는가?
- 다른 팀이 올라가면서 상대 점수가 밀리고 있지는 않은가?
- 점수가 정체/하락 중이면 그 원인이 정확히 진단되었는가?
- "이미 다 해봤다"는 변명을 하고 있지 않은가?

## 2. 반복 실수 방지 (Repetition Check)
- dead_ends에 기록된 실패 패턴을 다시 시도하고 있지 않은가?
- 같은 revert 메시지로 3회 이상 실패한 경로를 계속 시도하는가?

## 3. CLAUDE.md / analysis.md 준수 (Protocol Compliance)
- §4의 "drain ALL" mandate가 지켜지고 있는가?
- §7의 stuck 대응(코드를 다시 읽어라)이 적용되고 있는가?
- 식별한 target을 실행하지 않고 방치하고 있지 않은가?

## 4. 정직성 (Truthfulness)
- "all pools drained" 같은 주장이 실제 데이터와 부합하는가?
- 식별은 했지만 시도하지 않은 경로를 dead-end로 분류하지 않았는가?

## 5. 잔여 기회 포착 (Opportunity Detection)
- 다른 팀이 만점을 달성한 챌린지에서 우리가 못하는 이유를 분석했는가?
- 탐색하지 않은 경로가 남아있는데 "완료"를 선언하지 않았는가?
